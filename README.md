# 炉火 Kiln

Minecraft Java 版启动器。还在开发中，第一个能用的版本尚未发布。

## 打算做成什么样

- 下载并安装 Minecraft 各种版本：正式版、快照、远古版
- 一键装 Fabric、Quilt、NeoForge、Forge
- 在启动器里直接搜模组和整合包，点一下就装
- 微软账号登录，正版直接开玩
- 多个版本并存，存档和设置互不干扰
- 换台电脑登录，游戏配置自动同步

上面这些按顺序做。
